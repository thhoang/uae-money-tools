# uae-money-tools

Free UAE money calculators as a plain static site (HTML/CSS/JS, no framework, no build):

- Gratuity calculator (end of service, Article 51 of Federal Decree-Law No. 33 of 2021)
- VAT calculator (5% add/remove)
- Salary calculator (take-home, annual/daily/hourly, GPSSA 5% for Emiratis)
- Guides: how gratuity is calculated, limited vs unlimited contracts, UAE VAT guide

Deployed on Cloudflare Pages (`uae-money-tools.pages.dev`). Push to `main` to update.
